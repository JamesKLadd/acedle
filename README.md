# Acedle

A daily tennis roll game inspired by RNGdle. Roll a random season (1980–2026)
and a random year-end top-100 player from it. Their real stats earn badges,
and the badges add up to your score.

See [SPEC.md](./SPEC.md) for the full product and technical spec.

## Data

Match and ranking data comes from Jeff Sackmann's
[tennis_atp](https://github.com/JeffSackmann/tennis_atp) repository, licensed
under [CC BY-NC-SA 4.0](https://creativecommons.org/licenses/by-nc-sa/4.0/).
Acedle is a non-commercial fan project and isn't affiliated with the ATP Tour.
