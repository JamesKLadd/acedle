# Season data

One JSON file per rollable season, each a list of the year-end top-100
players (the current top 100 for the live season) with the stats the scoring
engine uses. The shape is `PlayerSeason` in `src/lib/data/types.ts`.

Generated by `npm run data:fetch && npm run data:build`. Don't edit by hand.
The live season (2026) is refreshed daily by `.github/workflows/refresh-data.yml`.
